Foklumi is an open-source (MIT) desktop focus timer. Instead of idle breaks, it turns them into short
vocabulary lessons, read aloud with text-to-speech.

It is built with Python and PySide6, has unit tests running in GitHub Actions, and ships as
PyInstaller builds.
